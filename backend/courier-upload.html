Excel column format — use exactly these headers (row order doesn't matter; matching is flexible):
DATE   STORECODE   COURIER NAME   TRACKING NUMBER   NO OF BOX   MOBILE NUMBER
MOBILE NUMBER is required (customers look up by it). If no separate docket/invoice number is provided, each row is keyed by its TRACKING NUMBER. Rows without a valid mobile are skipped.
